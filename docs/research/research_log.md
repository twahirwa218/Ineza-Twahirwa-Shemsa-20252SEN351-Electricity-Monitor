Research Log

Project Title

Electricity Consumption and Peak-Demand Monitoring System for Distribution Networks

1. Research Objective

The purpose of this research is to understand electricity consumption patterns, identify peak-demand periods, and explore ways to monitor electricity usage effectively.

2. Research Sources

No.	Source	Purpose
1	UCI Machine Learning Repository – Power Consumption of Tetouan City	Provides real electricity consumption data
2	Oracle PL/SQL Documentation	Supports database programming
3	International Energy Agency – Electricity 2024	Provides electricity industry information
4	Salam & El Hibaoui (2018) – Power Consumption Prediction	Supports electricity prediction research
5	Amara-Ouali et al. – Peak Electrical Load Forecasting	Supports peak-demand analysis
6	An existing electricity monitoring system	Helps identify features and limitations of current systems

3. Key Research Findings

* Electricity consumption changes over time.
* Different distribution zones can have different consumption patterns.
* Peak-demand monitoring can support better electricity planning.
* Database systems can organize and analyze large amounts of consumption data.
* PL/SQL can automate reports and generate alerts.

4. Research Gap

The proposed project will combine electricity consumption monitoring, peak-demand identification, automated alerts, and reporting in one Oracle database system.

6. Conclusion

The research supports developing a database system that helps monitor electricity consumption, identify peak-demand periods, and provide useful information for decision-making.

Initial research completed. Sources and findings will be verified and expanded during project development.
